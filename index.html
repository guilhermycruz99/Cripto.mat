📘 Matrizes

Bem-vindo ao estudo das Matrizes! Neste conteúdo vamos aprender o que são matrizes, como elas são representadas, quais são seus tipos, as principais operações matemáticas e como elas são utilizadas no sistema de criptografia do CRIPTO.MAT.

1️⃣ O que é uma Matriz?

Uma matriz é uma tabela formada por números organizados em linhas e colunas. Ela é utilizada para armazenar informações e realizar cálculos matemáticos de forma organizada.

Observe a matriz abaixo:

2
3
1
4

Essa matriz possui:

  • 2 linhas
  • 2 colunas
  • Ordem 2 × 2
Ordem = Número de Linhas × Número de Colunas

2️⃣ Elementos de uma Matriz

Cada número presente na matriz é chamado de elemento.

A =

[ 2 3 ]
[ 1 4 ]
  • a₁₁ = 2 → Linha 1, Coluna 1
  • a₁₂ = 3 → Linha 1, Coluna 2
  • a₂₁ = 1 → Linha 2, Coluna 1
  • a₂₂ = 4 → Linha 2, Coluna 2

3️⃣ Tipos de Matrizes

📌 Matriz Linha

Possui apenas uma linha.

[ 2 5 8 10 ]

📌 Matriz Coluna

Possui apenas uma coluna.

[ 2 ]
[ 5 ]
[ 8 ]

📌 Matriz Quadrada

Possui o mesmo número de linhas e colunas.

[ 1 2 ]
[ 3 4 ]

📌 Matriz Nula

Todos os elementos são iguais a zero.

[ 0 0 ]
[ 0 0 ]

📌 Matriz Diagonal

Apenas os elementos da diagonal principal são diferentes de zero.

[ 3 0 ]
[ 0 5 ]

📌 Matriz Identidade

Funciona como o número 1 na multiplicação comum.

[ 1 0 ]
[ 0 1 ]

4️⃣ Igualdade de Matrizes

Duas matrizes são iguais quando possuem a mesma ordem e os mesmos elementos nas mesmas posições.

[ 1 2 ]
[ 3 4 ]

=

[ 1 2 ]
[ 3 4 ]

A subtração também é realizada elemento por elemento.

Um escalar é um número real que multiplica todos os elementos da matriz.

📗 Sistemas Lineares

Bem-vindo ao estudo dos Sistemas Lineares! Neste conteúdo vamos aprender o que é um sistema linear, como resolver sistemas utilizando diferentes métodos e como eles são utilizados pelo CRIPTO.MAT para criar uma segunda camada de criptografia.

1️⃣ O que é um Sistema Linear?

Um sistema linear é um conjunto de duas ou mais equações que possuem variáveis em comum.

Resolver um sistema significa encontrar os valores das variáveis que satisfazem simultaneamente todas as equações.

2x + y = 10

x + 3y = 17

Nesse exemplo devemos encontrar os valores de x e y que tornam as duas equações verdadeiras ao mesmo tempo.

2️⃣ Elementos de um Sistema Linear

2x + y = 10

Nesta equação:

  • x e y são as incógnitas.
  • 2 e 1 são os coeficientes.
  • 10 é o termo independente.

As incógnitas representam valores desconhecidos que devem ser encontrados.

3️⃣ Classificação dos Sistemas Lineares

📌 Sistema Possível e Determinado (SPD)

Possui uma única solução.

x = 3
y = 4

📌 Sistema Possível e Indeterminado (SPI)

Possui infinitas soluções.

x + y = 4
2x + 2y = 8

📌 Sistema Impossível (SI)

Não possui solução.

x + y = 3
x + y = 8

4️⃣ Método da Substituição

Neste método isolamos uma variável em uma das equações e substituímos na outra.

x + y = 7
x = 7 - y

Em seguida substituímos esse valor na segunda equação.

2x + y = 11

Substituindo:

2(7 - y) + y = 11
14 - 2y + y = 11

y = 3

Agora substituímos y = 3 na primeira equação:

x + 3 = 7

x = 4

5️⃣ Método da Adição

O objetivo é eliminar uma das incógnitas somando ou subtraindo as equações.

x + y = 7
x - y = 1

Somando as equações:

2x = 8

x = 4

Substituindo:

4 + y = 7

y = 3

6️⃣ Método de Escalonamento

O escalonamento consiste em transformar o sistema em uma forma triangular, facilitando a resolução.

x + y = 7
2x + y = 11

Subtraindo a primeira equação da segunda:

x = 4

Substituindo:

y = 3

7️⃣ Representação Matricial

Todo sistema linear pode ser representado por matrizes.

2
1
1
3

Essa matriz contém os coeficientes das incógnitas do sistema.

8️⃣ Sistemas Lineares no CRIPTO.MAT

Após a criptografia matricial, o CRIPTO.MAT pode aplicar uma segunda camada de segurança utilizando um sistema linear.

x' = 2x + y

y' = x + 3y

Esse sistema transforma os valores produzidos pela matriz-chave em novos valores criptografados.

9️⃣ Exemplo com a Palavra BOLA

Após a multiplicação matricial obtemos:

44
57

Aplicando o sistema linear:

x' = 2(44) + 57
x' = 145

y' = 44 + 3(57)
y' = 215
145
215

Esses novos valores representam a segunda camada de criptografia.
