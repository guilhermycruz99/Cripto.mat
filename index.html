🔐 Como Funciona

O sistema CRIPTO.MAT usa matrizes e multiplicação matricial para transformar textos em códigos numéricos.

1. Conversão do Texto

Cada caractere do texto é convertido em um número.

A = 0
B = 1
C = 2
...

Exemplo:

O = 14
I = 8

2. Formação do Vetor

O texto vira um vetor matemático:

[14]
[08]

3. Matriz-Chave

O sistema utiliza uma matriz-chave para realizar a criptografia.

[2 3]
[1 4]

4. Multiplicação Matricial

A matriz-chave é multiplicada pelo vetor do texto.

[2 3] × [14]
[1 4]   [08]

Cálculo:

(2×14 + 3×8) = 52
(1×14 + 4×8) = 46

5. Aplicação do Módulo

O sistema utiliza aritmética modular para manter os números dentro do conjunto de caracteres.

52 mod 251 = 52
46 mod 251 = 46

6. Resultado Criptografado

O texto é convertido em uma sequência criptografada:

52-46

🔓 Como Funciona a Descriptografia

Para recuperar o texto, usamos a matriz inversa.

A⁻¹

Primeiro calculamos o determinante:

det(A)=ad−bc

Depois calculamos a matriz inversa modular.

[4 -3]
[-1 2]

A matriz inversa é multiplicada pelo vetor criptografado, recuperando o texto original.

Texto Recuperado:
OI

📌 Por que isso é seguro?

Sem conhecer a matriz-chave, é muito difícil recuperar o texto original.

Esse método é baseado na Cifra de Hill, um dos métodos clássicos de criptografia matemática.

2. O que é uma Matriz?

Uma matriz é uma organização de números distribuídos em linhas e colunas.

Pense nela como uma tabela matemática usada para guardar informações e fazer cálculos.

[2 5 8]
[1 4 6]

Nesse exemplo temos:

  • 2 linhas
  • 3 colunas
  • ordem 2 × 3

A ordem da matriz é sempre:

linhas × colunas

3. Elementos da Matriz

Cada número presente em uma matriz recebe o nome de elemento.

[4 2]
[7 9]

Observe:

  • 4 → linha 1, coluna 1
  • 2 → linha 1, coluna 2
  • 7 → linha 2, coluna 1
  • 9 → linha 2, coluna 2

Na matemática usamos a notação:

aᵢⱼ

Onde:

  • i = linha
  • j = coluna

Exemplo:

a₂₁ = 7

Significa: elemento da linha 2 coluna 1.

4. Ordem da Matriz

A ordem representa quantas linhas e colunas a matriz possui.

Exemplo:

[1 2]
[3 4]
[5 6]

Essa matriz possui:

  • 3 linhas
  • 2 colunas
Ordem = 3 × 2

5. Tipos de Matrizes

📌 Matriz Linha

Possui apenas uma linha.

[1 2 3]

📌 Matriz Coluna

Possui apenas uma coluna.

[4]

📌 Matriz Quadrada

📌 Matriz Identidade

Possui 1 na diagonal principal e 0 nos demais elementos.

[1 0 0]
[0 1 0]
[0 0 1]

Ela funciona como o número 1 da multiplicação.

Qualquer matriz multiplicada pela identidade continua igual.

A × I = A

📌 Matriz Nula

Todos os elementos são 0.

[0 0]
[0 0]

📌 Matriz Diagonal

Apenas a diagonal principal possui valores diferentes de zero.

[4 0]

📌 Matriz Escalar

[5 0]

📌 Matriz Transposta

É formada trocando linhas por colunas.

[3 4]

Aᵀ = [1 3]
[2 4]

7. Propriedades das Matrizes

Propriedade Comutativa

Na soma:

A + B = B + A

Porém na multiplicação:

A × B ≠ B × A

A ordem importa.

Propriedade Associativa

(A+B)+C=A+(B+C)

Elemento Neutro

A matriz identidade funciona como elemento neutro.

A × I = A

8. Determinante de Matrizes

O determinante é um número associado à matriz.

Ele ajuda a descobrir:

  • Se existe matriz inversa
  • Se sistemas possuem solução
  • Aplicações em criptografia

Determinante 2×2

Fórmula:

det(A)=ad−bc

Exemplo:

[2 3]
[1 4]

Cálculo:

(2×4) − (3×1)
8−3
= 5

Portanto:

det(A)=5

Determinante 3×3

Usamos a Regra de Sarrus.

[1 2 3]
[4 5 6]
[7 8 9]

Repetimos as duas primeiras colunas:

[1 2 3 1 2]
[4 5 6 4 5]
[7 8 9 7 8]

Depois fazemos:

diagonais positivas − diagonais negativas

Esse processo é muito usado em álgebra linear.

10. Matriz Inversa

A matriz inversa é uma das ideias mais importantes da Álgebra Linear.

Ela serve para “desfazer” uma multiplicação matricial.

Pense nela como uma operação inversa, semelhante à divisão.

Exemplo:

5 × 2 = 10

10 ÷ 2 = 5

Nas matrizes não existe divisão, então usamos a matriz inversa.

A × A⁻¹ = I

Onde:

  • A = matriz original
  • A⁻¹ = matriz inversa
  • I = matriz identidade

Isso significa que a matriz inversa “desfaz” a multiplicação da matriz.

📌 Quando uma matriz possui inversa?

Nem toda matriz possui inversa.

Para existir inversa:

  • A matriz deve ser quadrada
  • O determinante deve ser diferente de zero
det(A) ≠ 0

Se o determinante for zero, não existe inversa.

📌 Fórmula da Matriz Inversa (2×2)

Dada a matriz:

[a b]
[c d]

A fórmula da inversa é:

A⁻¹ = 1 ───── ad−bc

[ d −b ]
[ −c a ]

Observe:

  • trocamos a posição de a e d
  • b e c ficam negativos

Exemplo Resolvido

Vamos encontrar a inversa:

[2 3]
[1 4]

Primeiro calculamos o determinante:

det(A)=ad−bc
(2×4) − (3×1)
8−3=5

Agora montamos a inversa:

A⁻¹= 1/5

[4 -3]
[-1 2]

Essa matriz consegue desfazer a multiplicação da original.

🔐 Matriz Inversa no CRIPTO.MAT

No CRIPTO.MAT usamos:

Texto × Matriz-chave

para criptografar.

Depois usamos:

Texto criptografado × Matriz inversa

para recuperar o texto original.

Exemplo:

[1 4]

Criptografa a mensagem.

Depois:

[4 -3]
[-1 2]

recupera o texto.

Sem a matriz correta, é extremamente difícil descriptografar.

📗 Sistemas Lineares

Nesta seção você aprenderá sistemas lineares de forma simples, como se estivesse em uma aula com professor.

1. O que é um Sistema Linear?

Um sistema linear é um conjunto de equações que possuem variáveis em comum e precisam ser resolvidas ao mesmo tempo.

Exemplo:

2x + y = 10
x − y = 2

O objetivo é descobrir os valores de x e y.

2. Tipos de Sistemas

Sistema Possível Determinado (SPD)

Possui apenas uma solução.

x = 4
y = 2

Sistema Possível Indeterminado (SPI)

Possui infinitas soluções.

x + y = 10
2x + 2y = 20

Sistema Impossível (SI)

Não possui solução.

x + y = 4
x + y = 10

3. Método da Substituição

Vamos resolver:

x + y = 8
x − y = 2

Primeiro isolamos uma variável:

x = y + 2

Substituímos na outra equação:

(y + 2) + y = 8
2y + 2 = 8
2y = 6
y = 3

Agora encontramos x:

x = 3 + 2
x = 5

Resultado Final

x = 5
y = 3

4. Método da Adição

Exemplo:

x + y = 10
x − y = 2

Somando as equações:

2x = 12
x = 6

Substituindo:

6 + y = 10
y = 4

Resultado

x = 6
y = 4

5. Método de Escalonamento

O escalonamento organiza as equações em formato de matriz.

[2 1 | 10]
[1 -1 | 2]

Depois fazemos operações até encontrar as incógnitas.

6. Regra de Cramer

A Regra de Cramer utiliza determinantes para resolver sistemas lineares.

Fórmula:

x = Dx / D
y = Dy / D

Onde:

  • D = determinante principal
  • Dx = determinante de x
  • Dy = determinante de y

7. Sistemas Lineares com Matrizes

Podemos escrever um sistema usando matrizes:

[2 1] × [x] = [10]
[1 -1]   [y]   [2]

Isso conecta diretamente sistemas lineares com criptografia matricial, como o CRIPTO.MAT faz.
